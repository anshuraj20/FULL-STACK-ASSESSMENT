
# 🚀 FULL-STACK-ASSESSMENT

This is a full-stack web application built as a technical assessment project, demonstrating integration between a React-based frontend and a Node.js + Express backend, with MongoDB as the database.

---

## 📁 Project Structure

```
FULL-STACK-ASSESSMENT/
├── backend/       # Node.js + Express backend
│   ├── controller/
│   └── routes/
├── frontend/      # React frontend
│   ├── public/
│   └── src/
├── outputs/       # Output screenshots or logs
└── README.md
```

---

## 🛠️ Tech Stack

| Layer     | Technology            |
|-----------|------------------------|
| Frontend  | React, HTML, CSS       |
| Backend   | Node.js, Express       |
| Database  | MongoDB (Mongoose)     |

---

## 📦 Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/anshuraj20/FULL-STACK-ASSESSMENT.git
cd FULL-STACK-ASSESSMENT
```

### 2. Install Dependencies

#### Backend:
```bash
cd backend
npm install
```

#### Frontend:
```bash
cd ../frontend
npm install
```

### 3. Run the Project

#### Backend:
```bash
cd backend
npm start
```

#### Frontend:
```bash
cd frontend
npm start
```
